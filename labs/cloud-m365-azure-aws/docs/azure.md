# Azure

Mapeie assinatura, grupo de recursos, VM, VNet, sub-rede, NSG, Storage e Azure Monitor. Revise RBAC e exposição de portas administrativas. Em assinatura autorizada, comandos consultivos incluem az vm list, az network nsg list e az storage account list, após autenticação e seleção da assinatura correta.

Exercício: investigar indisponibilidade de VM fictícia, verificar estado, métricas, NSG, rotas e logs. Não abra portas administrativas para a Internet. Configure orçamento e alertas antes de provisionar recursos; alertas de orçamento não são limite rígido de cobrança.
