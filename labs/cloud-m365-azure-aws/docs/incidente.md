# INC-CLOUD-001 — Falha de acesso Microsoft 365

**Caso inteiramente fictício.** Usuário de demonstração relata falha de entrada. Verificar estado do serviço, licença, logs de entrada, políticas e métodos de autenticação. Escalonar alterações de acesso para equipe autorizada. Não desativar MFA como solução genérica. Validar recuperação e registrar evidências sanitizadas.

O auditor offline também sinaliza armazenamento público e acesso administrativo aberto em recursos fictícios. Esses sinais são hipóteses para revisão, não evidências de vulnerabilidades reais.
