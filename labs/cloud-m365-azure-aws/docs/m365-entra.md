# Microsoft 365 e Entra ID

Em tenant de testes autorizado, consulte usuários, grupos, licenças, estado de serviços e logs de entrada. Revise MFA, acesso condicional (conforme licenciamento), funções administrativas e menor privilégio. Use Microsoft Graph PowerShell com permissões de leitura aprovadas; Get-MgUser e Get-MgSubscribedSku são exemplos de consulta após autenticação autorizada. Não exporte dados pessoais.

Exchange Online: diferencie falha de autenticação, licença, caixa postal, DNS e indisponibilidade do serviço. Teams: verifique estado do serviço, políticas, licença e conectividade. Não altere registros DNS reais para realizar este exercício.

O campo MFA do inventário é uma hipótese didática, não uma medição de registro ou aplicação de MFA em Entra ID.
