# AWS

Mapeie EC2, VPC, sub-redes, security groups, S3, IAM e CloudWatch. Revise MFA, funções IAM, bloqueio de acesso público S3 e exposição administrativa. Em conta autorizada, exemplos consultivos são aws sts get-caller-identity, aws ec2 describe-instances e aws s3api get-public-access-block --bucket NOME_AUTORIZADO.

Exercício: investigar falha de acesso a instância fictícia, verificar estado, métricas, rotas e security groups. Não use chaves reais no repositório. Configure orçamento, alertas e plano de remoção de recursos antes de qualquer implantação; orçamento não garante bloqueio de custos.
