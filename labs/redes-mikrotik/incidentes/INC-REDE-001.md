# INC-REDE-001 — Falha de resolução DNS (simulação)

> **INCIDENTE FICTÍCIO.** Não houve indisponibilidade real, alteração de rede ou cliente afetado.

| Campo | Valor hipotético |
|---|---|
| Prioridade | P3 |
| Segmento | VLAN 20 — Usuários |
| Sintoma | Nome de serviço fictício não resolve |
| Alcance | Uma estação de laboratório |
| Causa simulada | Parâmetro DNS incorreto no DHCP fictício |
| Situação | Encerrado (exercício documental) |

## Linha do tempo hipotética

- 10:00 — Usuário fictício informa falha de acesso por nome.
- 10:05 — Analista confirma endereço IP e gateway.
- 10:10 — Diagnóstico diferencia falha de DNS de conectividade.
- 10:20 — Identificada hipótese de configuração DNS no DHCP.
- 10:30 — Mudança fictícia é aprovada e simulada.
- 10:40 — Resolução de nomes é validada no exercício.

## Prevenção

Validar opções DHCP, monitorar resolução DNS e documentar mudanças por VLAN. Os horários e resultados são inventados para fins de portfólio.
